# Лабораторная работа 14. Управление жизненным циклом DbContext в MVVM-приложениях.
Задание:
Модернизировать приложение «Телефонная книга», исправив проблему времени жизни DbContext.

Требования к доработке:
1) Заменить регистрацию AddDbContext на AddDbContextFactory в DI-контейнере.
2) Внедрить IDbContextFactory<ApplicationContext> в ViewModels вместо прямого внедрения контекста.
3) Переписать операцию чтения с использованием локального контекста.
4) Переписать операцию создания с использованием локального контекста.
5) Реализовать операцию редактирования с использованием паттерна Fetch-Modify-Save.
6) Реализовать операцию удаления с корректной работой с новым контекстом.
