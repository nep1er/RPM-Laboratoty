# Лабораторно-практическая работа No5. Структурные паттерны проектирования. Компоновщик, Фасад и Адаптер.

# Задание:
Разработать консольное приложение, моделирующее работу с файловой
системой, включающей:

• Локальную файловую систему (NTFS).
• Удалённую файловую систему (например, FTP).
• Облачное хранилище (имитация API Google Drive или Dropbox).


Приложение должно позволять:

• Строить иерархическую структуру из файлов и папок, используя паттерн Composite (файлы – листья, папки – компоновщики). Реализовать операции рекурсивного обхода (подсчёт размера, удаление, копирование).
• Интегрировать разные файловые системы через паттерн Adapter, предоставляющий единый интерфейс для основных операций (список содержимого, чтение, запись, удаление).
• Предоставить простой интерфейс для типовых сценариев через паттерн Facade (например, синхронизация локальной папки с облаком, создание резервной копии), скрывающий сложность рекурсивного обхода и вызовов адаптеров.
