# Лабораторная работа 12. Взаимодействие с базами данных в .NET. ADO.NET vs ORM. Обратная инженерия
Задание:
Выполнить интеграцию базы данных в существующее приложение «Телефонная книга» (из предыдущих лабораторных работ).

Требования к доработке:
1. Подключить к проекту необходимые NuGet-пакеты для работы с Entity Framework Core и выбранной СУБД (например, SQLite или SQL Server).
2. Создать новую базу данных в выбранной СУБД с именем "PhoneBookDB_ФАМИЛИЯ_ГРУППА" 
3. Используя средства обратной инженерии, восстановить классы сущностей и контекст данных по готовой базе данных.
4. Зарегистрировать DbContext в контейнере внедрения зависимостей (DI).
5. Обеспечить чтение списка контактов из базы данных при запуске приложения.
